# Base de Datos Relacional - Complejo Deportivo

Proyecto académico grupal desarrollado en el marco de la carrera de **Ingeniería Informática en UADE**, para la materia Ingeniería de Datos 1 (2026).

## Descripción

Diseño e implementación de una base de datos relacional utilizando Microsoft SQL Server, orientada a la gestión de un complejo deportivo con múltiples sedes, canchas y disciplinas.

El sistema permite modelar y administrar información relacionada con clientes, empleados, reservas, pagos, promociones y mantenimiento de instalaciones.

## Tecnologías y conocimientos aplicados

- Microsoft SQL Server
- SQL y T-SQL
- Diseño y modelado de bases de datos relacionales
- Modelo Entidad-Relación (MER y DER)
- Claves primarias y foráneas
- Consultas SQL (JOIN, subconsultas y funciones de agregación)
- Procedimientos almacenados (Stored Procedures)
- Vistas (Views)
- Triggers para validaciones y auditoría
- Integridad referencial

## Funcionalidades contempladas

- Gestión de clientes, empleados y sedes.
- Administración de canchas y disciplinas deportivas.
- Registro y consulta de reservas.
- Gestión de pagos y métodos de pago.
- Aplicación de promociones.
- Registro de tareas de mantenimiento.
- Consulta de disponibilidad de canchas.
- Reportes de ingresos.

## Estructura del repositorio

- `sql/`: scripts de creación de tablas, carga de datos, consultas, vistas, procedimientos almacenados y triggers.
- `documentacion/`: documentación del proyecto, requisitos y modelado de la base de datos.

## Documentación

El proyecto incluye el relevamiento de necesidades, requisitos funcionales y no funcionales, modelo entidad-relación y diagrama de la base de datos.
